Evaluator Loop Explorer

The prototype proposes explanations of each evaluator's ratings, builds one-detail edits of applications to test them, and confirms only what the evaluator's re-ratings support. Here it runs on simulated panels whose true preferences are known, so you can see what it finds and what it misses.

    Your own data
    
        
    The prototype also runs on a real panel, where every evaluator rated the same applications. Real data has no re-ratings yet, so it stops after screening. For each evaluator you get the hypotheses an AI model proposed, whether the statistical copy of that evaluator supports them, example edits, and the edited applications a re-rating study would use. Nothing is confirmed until evaluators re-rate.
    
        
    This runs in the local app, on your own computer, so your applications go only to the AI provider you choose. Check that your data permissions allow that before running it.
    
        
    
        
    pip install -e ".[app]"
python -m evloop app
    
        
    The app opens in your browser. Choose "Your own data", upload the files, set up the AI model in the sidebar, and run. It can also make example files from a simulated panel to try first.
